# Oregairu · 三种放学后的心情

在 Typora 的「主题」菜单中切换以下版本：

| 菜单名称（可能按空格显示） | 角色 | 配色 |
| --- | --- | --- |
| Oregairu Yukino | 雪之下雪乃 | 冰蓝、冷白 |
| Oregairu Yui | 由比滨结衣 | 暖粉、浅暖白 |
| Oregairu Hachiman | 比企谷八幡 | 灰绿、雾白 |

原来的 Oregairu 保留。三个新版本各显示一位角色，沿用简洁标题、左对齐正文和浅色代码块。立绘略缩小，正文左侧留白由 184px 调整为 172px。窄窗口缩小立绘，打印时隐藏。

安装时将四个入口 CSS（含共用的 `oregairu.css`）和整个 `oregairu` 资源文件夹一起复制到 Typora 的主题目录。三个角色版本通过 `@import` 引用共用主题，请保留 `oregairu.css`。

想只改某个角色版本时，对应的个人配置文件是 `oregairu-yukino.user.css`、`oregairu-yui.user.css`、`oregairu-hachiman.user.css`。原来的 `oregairu.user.css` 不会自动应用到这些新名称。

立绘为 AI 生成的非官方同人图。结衣和八幡使用内置 imagegen 生成，雪乃沿用上一版。生成提示概要：透明背景、单人全身、春物对应角色与校服、细腻动漫线稿和柔和阴影、自然站姿、适合 140×270px 显示，无文字和水印。结衣使用粉桃短发侧团子头、微笑持书包；八幡使用黑色乱发、慵懒眼神、一手插袋一手持书。

验证范围：安装文件一致性、资源路径、CSS 结构。实际 Typora 窗口与 PDF 导出效果仍需要查看。
