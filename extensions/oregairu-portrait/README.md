# Oregairu 动态立绘

面向 Typora Community Plugin 的本地扩展，ID：local.oregairu-portrait，版本：0.0.3。

只对声明 --oregairu-live-role 的 Oregairu 当前版及 V0.0.3 生效。正文状态显示右下立绘，默认70%透明度，文字行覆盖处使用柔边遮罩；空文档恢复主题自带合照扉页。

## 安装

安装兼容的社区插件加载器后，将本目录放到其 plugins 目录，并在已安装插件中启用。若笔记库使用独立插件配置，需要在对应笔记库中启用。详见仓库根目录 README.md。

不要复制其他设备的插件设置文件。扩展不会修改 Typora 程序文件，也不包含网络请求。

## 卸载

在插件管理中关闭本扩展，完全重启 Typora。主题会退回静态立绘。可再删除本扩展目录，保留其他插件及其配置。

## 验证范围

已通过脚本语法与安装文件检查，并在 Windows 本机使用。其他平台未完整验证；性能与打印结果以实际文档为准。restore 是开发设备的本地恢复目录，不随 Git 仓库或发布包分发。
