# Oregairu V0.0.1 便携安装包

包含雪乃·冰蓝、结衣·暖粉、八幡·灰绿三个独立主题，以及全部配套立绘。不需要其他版本的 CSS。

## 安装到另一台设备

1. 解压本压缩包。
2. 在 Typora 中进入「偏好设置 → 外观 → 打开主题文件夹」。不同系统的菜单文字可能略有区别，以软件实际菜单为准。
3. 将三个 `.css` 文件和整个 `oregairu` 文件夹一起复制到打开的主题目录。CSS 必须直接放在主题目录根层级，不要连外层解压文件夹一起放入。
4. 完全退出并重新打开 Typora，在「主题」菜单选择对应的 Oregairu 角色 V0.0.1。

正确结构：

```text
themes/
├── oregairu-yukino-v0.0.1.css
├── oregairu-yui-v0.0.1.css
├── oregairu-hachiman-v0.0.1.css
└── oregairu/
    ├── yukino.png
    ├── yui.png
    └── hachiman.png
```

本包是保留的 V0.0.1 版本，不含 V0.0.2 的空白页合照与后续排版调整。字体使用本机字体回退，不同设备可能略有区别。不同系统或 Typora 版本的侧栏布局与立绘位置可能需要微调。

如果目标设备已经有同名文件，请先备份，再决定是否覆盖。资源文件夹也可能被其他 Oregairu 版本共用，不要整目录替换或删除其他版本独有的文件。
