# Oregairu V0.0.3

当前工作版的正式归档。三款角色主题：雪乃·冰蓝、结衣·暖粉、八幡·灰绿。

## 内容

保留 V0.0.2 的正文排版、合照扉页与滚动修复，增加右下角动态立绘：空白区域70%透明度，文字行覆盖处柔和渐隐。代码块和表格在立绘之上。

## 安装

1. 将三个带 v0.0.3 名称的 CSS 和 oregairu 资源文件夹复制到 Typora 主题目录。CSS 可独立使用，不依赖根目录共用 CSS。
2. 动态渐隐需要兼容的 Typora 社区插件加载器。本归档不自动安装加载器。
3. 将 extension/local.oregairu-portrait 复制到社区加载器的 plugins 目录，在插件管理中启用「Oregairu 动态立绘」。若笔记库使用独立插件配置，也需要在该笔记库中启用。
4. 完全退出并重新打开 Typora，选择 Oregairu 角色名 V0.0.3。

如果没有启用扩展，CSS 仍可加载，但会显示原左下立绘，不提供右下动态渐隐。

本机已经安装并启用扩展，不带版本号的三个入口当前同样对应 V0.0.3。V0.0.1 和 V0.0.2 归档不变。恢复备份只保留在开发目录，不包含在此归档内。
布局更新：正文区域居中，最大宽度900px（含左右内边距），文字左对齐；正文16px，标题28/23/19px。右下立绘及动态渐隐保留。
