# Oregairu V0.0.2

历史版本归档，提供雪乃·冰蓝、结衣·暖粉、八幡·灰绿三个主题。

此版包含左下角静态角色立绘、空白文档合照扉页、16px 正文与标题层级优化，以及编辑区滚动修复。它不包含 V0.0.3 的右下角动态立绘扩展和后续居中阅读布局。

## 安装

1. 解压本包，在 Typora 打开「偏好设置 → 外观 → 打开主题文件夹」。
2. 将三个带 v0.0.2 名称的 CSS 和整个 oregairu 文件夹复制进去。CSS 必须直接放在主题目录根层级。
3. 完全退出并重新打开 Typora，在主题菜单选择对应角色的 V0.0.2。

三个 CSS 均为独立文件，不依赖其他版本的共用样式或插件。已有同名资源时请先备份，不要删除其他主题独有的文件。

该版本作为历史原样归档提供，未应用 V0.0.3 后来的扉页构图和布局修正。不同 Typora 版本或系统的空白文档识别、侧栏、字体和导出效果可能存在差异。
