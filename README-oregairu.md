# Oregairu · 春物 Typora 主题

当前版本为 **V0.0.3**，提供雪乃·冰蓝、结衣·暖粉、八幡·灰绿。V0.0.1 独立保留。

## 目录

| 位置 | 内容 |
| --- | --- |
| `releases/` | 可复制到其他设备的发布压缩包 |
| `versions/V0.0.1/` | V0.0.1 完整独立主题与资源 |
| `versions/V0.0.2/` | V0.0.2 完整独立主题与资源 |
| `versions/V0.0.3/` | V0.0.3 主题、立绘扩展与安装说明 |
| `docs/` | 角色版本说明 |
| `examples/` | Markdown 排版示例 |
| `proposals/` | 排版候选样式，不是安装文件 |
| 根目录的 CSS 与 `oregairu/` | 当前开发与安装源文件 |

## 下载与安装

跨设备使用 V0.0.1，请取用 [Oregairu-V0.0.1.zip](releases/Oregairu-V0.0.1.zip)，包内附完整安装说明。

安装当前开发版时，将根目录的 `oregairu.css`、三个 `oregairu-角色名.css` 及 `oregairu/` 资源目录一起复制到 Typora「偏好设置 → 外观 → 打开主题文件夹」所打开的位置，然后重启并选择主题。

安装归档版本时，使用对应 `versions` 子目录中的带版本号 CSS 和 `oregairu/` 资源目录。带版本号 CSS 是独立文件，不依赖根目录的共用 CSS。

不要把整个项目目录直接放入 Typora 的主题文件夹。复制前先备份目标设备上的同名文件。
